## Flagship Platforms

Four large-scale platforms in active development, sequenced for delivery.

### 🎓 FundsLink Academy — National Education Funding Platform
**Problem:** 342,000+ South African students are excluded yearly due to fragmented bursary applications and unused funding sources.

**Solution:** A single application platform connecting students with bursaries, NSFAS, SETA funds, scholarships, and emergency support — powered by an AI scholarship-matching engine.

**Stack:** Next.js → API Routes → Service Layer → Prisma → PostgreSQL + Python/FastAPI AI service

**Status:** 🔵 Active Development (Phase 1)

---

### 🏘️ Maphophe Community System — Digital Governance for Villages
**Problem:** Rural villages lack digital infrastructure for governance, communication, and service delivery.

**Solution:** A village-level platform for announcements, service requests, community voting, and local governance — built for low-connectivity environments.

**Stack:** Next.js → API Routes → Service Layer → Prisma → PostgreSQL

**Status:** 🟢 Design Complete (Phase 2)

---

### 🏦 KSDRILL Reserve Bank — Discipline-Driven Savings Platform
**Problem:** Many people struggle with consistent savings habits and lack accessible microfinance tools.

**Solution:** A digital savings bank with goal-setting, automated deposits, interest tracking, and financial discipline features.

**Stack:** Next.js → API Routes → Service Layer → Prisma → PostgreSQL

**Status:** 🔵 Design Complete (Phase 3)

---

### 🤝 SyncUp — Creator Collaboration Platform
**Problem:** Creators struggle to find collaborators; existing platforms lack structured negotiation.

**Solution:** A platform with template-based negotiation, privacy protection, drop subscriptions, and a structured 10-message collaboration workflow.

**Stack:** Next.js → API Routes → Service Layer → Prisma → PostgreSQL

**Status:** 🟠 Design Complete (Phase 4)

## Engineering Philosophy

**Design-first** — every feature's logic is human-defined before any code is written.

**Sequential development** — one system at a time, no forward dependencies, no shortcuts.

**Separation of concerns** — UI, logic, and configuration stay fully independent.

**Configuration-driven** — theme, navigation, features, and AI services controlled via JSON.

**AI as a core component** — not a feature bolted on, but a fundamental layer driving insights, predictions, and automation.
