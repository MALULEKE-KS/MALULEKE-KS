### FundsLink Academy

A national education funding platform designed to eliminate student exclusion in South Africa.

Problem it solves:

• 342,000+ students excluded yearly  
• billions in unused funding sources  
• fragmented bursary applications

Solution:

A **single application platform** that matches students with:

• bursaries  
• NSFAS  
• SETA funds  
• scholarships  
• emergency support

Technology

React • Node.js • PostgreSQL • AI matching systems
