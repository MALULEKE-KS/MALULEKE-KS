## AI Engineering Focus

### Agentic AI Systems
Building autonomous agents that perceive, reason, and execute using:
- **LangChain/LangChain4j** for agent orchestration
- **Chain-of-thought reasoning** and planning algorithms
- **Tool use** (APIs, databases, external services)
- **Memory modules** (short-term + long-term context)

### RAG (Retrieval-Augmented Generation)
Production RAG implementations with:
- **Document chunking & embedding strategies**
- **Vector databases** (ChromaDB, Weaviate, Pinecone)
- **Hybrid search** (keyword + semantic)
- **Citation & grounding** to reduce hallucinations
- **Metadata filtering** for multi-document systems

### LLM Integration
- **Local models** via Ollama (Mistral, Llama)
- **Cloud models** (OpenAI, Claude)
- **Prompt engineering** & templating
- **Structured output** (JSON schema validation)
- **Streaming responses** (SSE/WebSockets)

### Production AI Patterns
- **Confidence thresholds** & fallback flows
- **Human-in-the-loop** review workflows
- **Observability** (retrieval quality, latency, costs)
- **Guardrails** & refusal behavior
- **A/B testing** for prompt versions
