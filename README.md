## 💻 Projects I've Built

### MediCare Pro - Healthcare Management
**React · Spring Boot · PostgreSQL · JWT · Docker**

A healthcare platform connecting patients with doctors. Patients can book appointments and view records; doctors can manage schedules and patient histories.

- Built REST APIs with Spring Boot for appointment and user management
- Created React components for dashboard views and forms
- Implemented JWT authentication with role-based access (patient/doctor/admin)
- Containerized with Docker for consistent deployment

### TaskFlow - Project Management Tool
**React · Node.js · MongoDB · Tailwind**

A task management application for teams to track projects and collaborate.

- Developed drag-and-drop interface for task board
- Built RESTful API with Node.js and Express
- Implemented real-time updates using WebSockets
- Used Tailwind for responsive design

### Personal Portfolio & Blog
**React · Markdown · Netlify**

A clean personal site to showcase projects and write about things I'm learning.

- Built with React and React Router
- Content managed through Markdown files
- Deployed on Netlify with continuous deployment
