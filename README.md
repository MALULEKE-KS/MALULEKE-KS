## How I work

1. **Agile delivery.** Work moves in small pieces, each one working and tested, shipped and reviewed in short sprints.
2. **The full software life cycle (SDLC).** Plan, design, build, test, release and maintain, with every stage written down.
3. **The database life cycle (DBLC).** The data is designed, built and evolved as carefully as the code.
4. **No surprises.** When something goes wrong, it's easy to see and quick to fix.
